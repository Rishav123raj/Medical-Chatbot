# Medical-Chatbot

This is a medical assistance chatbot built using Langchain, Vector Embeddings and Chromadb as vector database used for providing assistance to users on certain medicinal questions.

# Core Features
- Trained and evaluated on "The Gale Encyclopedia of Medicine" for authoritative medical knowledge.
- Utilizes semantic embeddings stored in ChromaDB for efficient vector-based information retrieval.
- Employs the Gemini 2.0 Flash model to generate fast, structured, and context-aware responses.
- Features a responsive HTML/CSS frontend integrated with a Flask backend for seamless interaction.
